# Dypocrypha frontend

React/Vite frontend. `maintenance/2026-10` contains the server workspace maintenance snapshot from 2026-10-29; `main` is unchanged.

## Development

Use Node.js 24 and npm. Run `npm ci`, then `npm run dev`. For a separate backend, copy `.env.example` to `.env.local` and set the public `VITE_API_BASE_URL`. With no override, API requests use the current page origin. VITE variables are public browser code, never secrets.

## Verification and build

Run `node --test tests/*.test.mjs` and `npm run build`. PDF.js assets are generated by npm postinstall/prebuild and are not committed. Upload the contents of `dist` through the existing deployment process.

## Exclusions

Credentials, certificates, local environment files, logs, editor settings, generated assets and build output are ignored. This branch does not deploy automatically. Existing commits on the repository can still contain previously tracked files; `.gitignore` does not remove history.
